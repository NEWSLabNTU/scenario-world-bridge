# 060: A signal table generated beside its map was not in the datasets' form

**Severity**: low. The generated table works, but it cannot join a map dataset as it is. Its
`lanelet2_map:` names a path on the generating host, and the dataset's own layout is a
symlink rather than the file, so it has to be fixed by hand first. **Status**: fixed on
main (scensim_carla_world 11f9922). **Found**: 2026-11-19, coop 118, adding a town to a
map dataset.

## What happens

`scensim_carla_world --generate-signal-table <map dir>`, run without a `state_dir`, wrote:

- `<map>/traffic_lights.yaml`, with `lanelet2_map: /home/<user>/.../lanelet2_map.osm`, under
  a header for a state directory ("Generated by scensim_carla_world (at an Initialize...)");
- `<map>/carla/traffic_lights.yaml`, a symlink to `../traffic_lights.yaml`.

The map datasets (carla-town-autoware-maps) ship `<town>/carla/traffic_lights.yaml` as the
file itself, with `lanelet2_map: lanelet2_map.osm` and a header for the town.

## Cause

`resolved_signals::write_table` had one form for every destination: the state directory's.
That form is the top-level file, with an absolute map path and the `carla/` link.

## Fix

The table is now written by destination (`resolved_signals::write`):

- **Beside the map** (no state directory, the generator or an Initialize): the datasets'
  form. The file itself goes at `<map>/carla/traffic_lights.yaml`, replacing the link,
  with `lanelet2_map` relative to the map directory and the datasets' header.
  - A `<map>/traffic_lights.yaml` that an older generator left (its first line says so) is
    removed, since readers take that file first.
  - A user's own file there is kept, and a WARN names it.
- **In a state directory**: unchanged.

Every reader already takes `carla/traffic_lights.yaml` when there is no top-level table:
the bridge, acb_bridge and the server's own check.

## Test

`resolved_signals.rs`, `beside_the_map_the_table_is_written_as_the_datasets_ship_it`:

- over a table in the old form, the write leaves the file itself at `carla/`, with the
  datasets' header, a relative `lanelet2_map` and `town:`;
- the old top-level file is gone, the table is found and checks clean;
- a user's top-level file is kept;
- a state-directory write keeps its old form.

scensim_carla_world: 194 tests pass, clippy and fmt are clean.

Not run live: the generator needs a CARLA, and the GPU was taken by other work.
