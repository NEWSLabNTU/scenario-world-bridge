# scensim

scensim runs driving scenarios in simulation: an OpenSCENARIO scenario, the autopilot under
test, and CARLA or Isaac Sim as the world.

This package is its front end: `pip install scensim`, then `scensim install` downloads the
prebuilt scensim for your ROS 2 release. See
[Install](https://github.com/NEWSLabNTU/scensim/blob/main/docs/getting-started/install.md).
